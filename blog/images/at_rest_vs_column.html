Encryption at rest is not the same as column-level encryption
Both protect against different attackers. You usually want both.
PLATFORM-MANAGED

Encryption at rest

The whole disk volume is encrypted with a key managed by Databricks (or your AKV/KMS-backed CMK at the workspace level).
📦 Attacker steals a backup file off S3 / Blob
unreadable bytes — needs the disk-level key
👤 Authenticated DB user runs SELECT *
123-45-6789 · alice@acme.com · 4111111111111111
🔧 Internal DBA reads pg_dump output
123-45-6789 · alice@acme.com · 4111111111111111
APP-MANAGED (CMK + pgcrypto)

Column-level encryption + masking

Each PII column is ciphertext in the table; only an authorized role can call the decrypt function.
📦 Attacker steals a backup file off S3 / Blob
unreadable bytes — needs both keys
👤 Authenticated DB user (pii_full_access) runs SELECT *
123-45-6789 · alice@acme.com · 4111111111111111
👤 Authenticated DB user (pii_masked) runs SELECT *
XXX-XX-6789 · a***@acme.com · ************1111
🔧 Internal DBA reads pg_dump output
\\xc30d04070302... (bytea ciphertext only)
